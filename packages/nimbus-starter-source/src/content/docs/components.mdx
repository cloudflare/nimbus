Every `.mdx` file can use these components without an import. Each one is a file in `src/components/ui/`, so you can change how it looks or works.

## Aside

Set a note, tip, caution, or warning apart from the text around it.

<Aside type="note">
  Pages are validated at build time.
</Aside>

<Aside type="caution" title="Before you deploy">
  Set `site` in `astro.config.ts` to your production URL.
</Aside>

```mdx
<Aside type="note">
  Pages are validated at build time.
</Aside>

<Aside type="caution" title="Before you deploy">
  Set `site` in `astro.config.ts` to your production URL.
</Aside>
```

| Prop | Value |
|---|---|
| `type` | `note` (default), `tip`, `caution`, or `danger` |
| `title` | Text above the content. Defaults to the type's name. |
| `icon` | Any `ph:` icon name, in place of the type's icon. |

For a title with formatting, pass it as a slot: `<Fragment slot="title">Uses <code>env</code></Fragment>`.

## Tabs

Show the same content in several variants. Give tabs a `syncKey`, and the reader's choice carries over to every set of tabs with the same key.

<Tabs syncKey="os">
  <TabItem label="macOS">
    Press <kbd>⌘</kbd> <kbd>K</kbd> to search.
  </TabItem>
  <TabItem label="Windows">
    Press <kbd>Ctrl</kbd> <kbd>K</kbd> to search.
  </TabItem>
</Tabs>

```mdx
<Tabs syncKey="os">
  <TabItem label="macOS">
    Press <kbd>⌘</kbd> <kbd>K</kbd> to search.
  </TabItem>
  <TabItem label="Windows">
    Press <kbd>Ctrl</kbd> <kbd>K</kbd> to search.
  </TabItem>
</Tabs>
```

| Prop | Value |
|---|---|
| `syncKey` on `Tabs` | Tabs with the same key switch together, and remember the choice. |
| `label` on `TabItem` | The tab's name. Required. |

## Cards

Link readers to the next places to go, in a grid that stacks on small screens.

    Create an `.mdx` file in `src/content/docs/`.
  </Card>
  <Card title="Change the theme" icon="ph:palette">

  </Card>
</CardGrid>

<CardGrid>
  <Card title="Write a page" icon="ph:pencil-simple">

  </Card>

    Edit the colour and type tokens in `src/styles/globals.css`.
  </Card>

| Prop | Value |
|---|---|
| `title` on `Card` | The card's heading. Also accepts a `title` slot. |
| `icon` on `Card` | Any `ph:` icon name. Also accepts an `icon` slot. |

Icons come from [Phosphor](https://phosphoricons.com): use any name with the `ph:` prefix.

## Restyle any part

Every part of every component has a `data-slot` attribute, so you can restyle one piece from `src/styles/globals.css` without editing the component.

```css title="src/styles/globals.css"
[data-slot="card-title"] {
  letter-spacing: -0.01em;
}
```

Corners come from two tokens in the same file: `--nb-radius` for cards, callouts, code blocks and buttons, and `--nb-radius-sm` for the small marks inside them. Change them to re-round the whole site.
