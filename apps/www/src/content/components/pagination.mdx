---
title: Pagination
tagline: "Previous / next links at the bottom of a doc page — driven by the sidebar tree."
props:
  - name: prevNext
    type: "{ prev?: { label: string; href: string }; next?: { label: string; href: string } }"
    description: Sibling page references. Either side can be omitted (first / last page). Ignored when you pass `PaginationLink` children.
  - name: prevLabel
    type: string
    defaultValue: '"Previous"'
    description: Caption above the previous page's title.
  - name: nextLabel
    type: string
    defaultValue: '"Next"'
    description: Caption above the next page's title.
  - name: keys
    type: boolean
    defaultValue: "true"
    description: "`[` and `]` (keys set in `src/lib/shortcuts.ts`) move to the previous and next page: from anywhere on the page for a bar built from `prevNext`, while the reader has single-key shortcuts on; from inside the bar for one with composed links. Set `false` to turn a bar's keys off."
---
