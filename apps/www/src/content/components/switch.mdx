### React to a change

A click flips `aria-checked` and fires a bubbling `change` event. A script that owns the state elsewhere sets `aria-checked` itself.

```astro
<Switch id="compact-mode">Compact mode</Switch>

<script>
  const toggle = document.getElementById("compact-mode")!;
  toggle.addEventListener("change", () => {
    document.documentElement.dataset.compact = toggle.getAttribute("aria-checked")!;
  });
</script>
```

## Accessibility

- It's a `<button role="switch">` with `aria-checked`, so screen readers announce "switch, on" or "switch, off".
- Space and Enter flip it, as with any button.
- Without a visible label, give it an `aria-label`.
