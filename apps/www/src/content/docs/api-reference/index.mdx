Nimbus generates API reference pages from a spec: one page per operation, tag and webhook, with search, Markdown versions and `llms.txt` entries. It reads OpenAPI 3.x today.

- [Cite API pages](/api-reference/citations): link to an operation from prose by its coordinate.
- [API versions](/api-reference/versions): serve several versions of an API, with a version picker.
- [Large APIs](/api-reference/large-apis): keep pages small and builds fast for big specs.
- [OpenAPI](/api-reference/openapi/setup): add a reference from an OpenAPI document.
