Every Nimbus site publishes a Markdown version of each page and an `llms.txt` index. These pages cover what else it can serve, and how to change what it publishes.

- [Docs for agents](/ai/docs-for-agents): everything an agent can read from your site, and how it finds it.
- [Markdown and llms.txt](/ai/publish-markdown): the Markdown versions and indexes, and how they're built.
- [Override generated Markdown](/ai/override-markdown): change a page's Markdown, an index or a share card.
- [Serve Markdown at page URLs](/ai/markdown-negotiation): answer `Accept: text/markdown` at a page's own URL.
- [Agent discovery](/ai/agent-discovery): the files and headers agents read to find your site.
- [Remote MCP server](/ai/remote-mcp): let agents read your docs as an MCP server.
- [Publish Agent Skills](/ai/agent-skills): publish skills agents can install from your site.
- [Let browser agents search your docs](/ai/webmcp): a WebMCP search tool on every page.
