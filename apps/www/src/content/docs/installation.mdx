One command sets up a project with layouts, components, content schemas, search, sitemap, OG images, and a Markdown version of every page.

## Requirements

- **Node** 22.12 or later
- **A package manager** — npm, pnpm, yarn, or bun
- **Git** — for edit links and last-updated dates

## Scaffold

<PackageManagers type="create" pkg="@cloudflare/nimbus-docs@latest" />

The scaffolder asks:

<Steps>
  <Step title="Directory">
    Where to create the project.
  </Step>
  <Step title="Starter content">
    **Getting started guide + example pages**, or **Empty**, just the shell for your own content. Flag: `--content starter|empty`.
  </Step>
  <Step title="Package manager">
    npm, pnpm, yarn, or bun. It installs dependencies with your choice unless you pass `--skip-install`. Flag: `--package-manager <pm>`.
  </Step>
  <Step title="Git">
    Whether to initialize a repository. Flag: `--no-git` to skip.
  </Step>
  <Step title="Output mode">
    **Static** prerenders every content collection route and deploys anywhere. **Server** renders those routes on request. You can override individual collections later.
  </Step>
  <Step title="Deploy target or adapter">
    Static output asks for a deploy target: Cloudflare or another static host (flag: `--deploy cloudflare|other`). Server output offers Cloudflare; the `--adapter` flag also accepts `vercel`, `netlify`, and `node`.
  </Step>
</Steps>

Pass `--yes` to accept every default without prompts. Without a terminal, such as in CI or when an agent runs it, `--yes` is required. Pass `--help` to list every flag.

## What lands in your repo

<FileTree>
- my-docs/
  - src/
    - components/
      - ui/
    - content/
      - docs/
    - pages/
    - styles/
      - globals.css
    - components.ts
  - astro.config.ts
  - package.json
</FileTree>

The `nimbus-docs` npm package ships the invisible plumbing (integration, data helpers, schemas). Everything visible — components under `src/components/`, MDX content under `src/content/docs/`, routes under `src/pages/`, design tokens in `src/styles/globals.css`, and the MDX globals registry at `src/components.ts` — copies into your repo and is yours to edit.

## Run

<PackageManagers pkg="dev" type="run" />

Then open the printed URL.

## Build and deploy

<PackageManagers pkg="build" type="run" />

Static scaffolds emit `dist/` for any static host. Cloudflare server scaffolds request-render canonical content collection routes and include the appropriate `wrangler.jsonc` and a `deploy` script.

<Aside type="tip">
  After scaffolding, run `nimbus-docs add <slug>` to install components from the registry. See [Adding components](/adding-components) for the workflow.
</Aside>
