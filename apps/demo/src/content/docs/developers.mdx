Sign up, create a key in the dashboard, and make a request: no sales call, no card for test keys.

## Plans

| Plan | Keys | Price | Limits |
| --- | --- | --- | --- |
| Free | `wx_test_` keys: the sandbox, with realistic fixed data for every endpoint | Free, no card | 10 requests a second, 10,000 a day |
| Pay as you go | `wx_live_` keys: live data | Per request, billed monthly | Per product; see [Rate limits](/concepts/rate-limits) |

Both are self-serve: create, scope and revoke keys under **API keys** in the dashboard. A test key works with every endpoint and returns the response shapes a live key does, so code written against the sandbox runs unchanged with a live key.
