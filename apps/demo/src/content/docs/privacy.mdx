This page covers two things: the docs site you're reading, which is real, and the Sample Co API, which is fictional.

## This site

demo.nimbus-docs.com sets no cookies and loads no analytics or advertising scripts. Fonts, search and images are served from this site.

Your browser keeps a few preferences for this site, and they never leave it: light or dark mode, the code-sample language you last chose, which sidebar groups are open, and whether you closed a banner. Clearing the site's data in your browser removes them.

The site runs on Cloudflare. Cloudflare processes each request (your IP address and the page asked for) to serve and protect the site, as its [privacy policy](https://www.cloudflare.com/privacypolicy/) describes. The search box searches an index downloaded to your browser, so what you type isn't sent anywhere.

## The Sample Co API

The API at `api.weather.example` doesn't exist. A real weather API would record each request's key, endpoint, time and coordinates for billing, rate limits and abuse prevention, keep them for a stated period, and never sell them. Its privacy page would say how long, who can see them, and how to ask for a copy or a deletion.
