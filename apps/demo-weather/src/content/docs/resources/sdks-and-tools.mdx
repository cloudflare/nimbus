You can call the API with any HTTP client. These make it quicker.

## Node.js library

The library wraps every v2 endpoint with typed requests and responses, retries `429` and `5xx` for you, and follows pagination cursors.

<PackageManagers pkg="@sample-co/weather" />

```js
import { Weather } from "@sample-co/weather";

const weather = new Weather({ apiKey: process.env.WEATHER_API_KEY });
const forecast = await weather.forecasts.daily({ latitude: 59.9139, longitude: 10.7522, days: 7 });
```

A small alerting service built on the library: `index.ts` creates the client and the subscription, `webhook.ts` verifies and handles deliveries, and `.env` holds `WEATHER_API_KEY` and the signing secret.
